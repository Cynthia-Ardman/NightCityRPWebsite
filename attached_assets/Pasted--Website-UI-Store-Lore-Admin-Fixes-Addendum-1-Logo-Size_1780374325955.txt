## 10.3 Archived Request Behavior

For archived/closed requests, the current UI shows **View and Respond**.

If a request is archived/closed entirely, the only available action should be:

`Reopen`

**Acceptance criteria**

* Archived/closed requests only show Reopen as the active action.
* View-only reading may still be allowed, but responding is disabled while archived.
* Reopened requests regain normal response/action tools.
* Reopen action is logged.
