Objective

Gun catalog feature for NCRP portal:

    Show + let FIXERS set a "required cyberware to operate" on a gun in three places: the gun catalog/gunlist, a gun in a gunstore (store_stock), and a gun in a player's inventory.
    Catalog guns: pictures (image_url already exists), a Cyberpunk wiki link, and a Discord prefab-thread link — fixer-editable.
    Hover a gun's name -> image popup preview (catalog gunlist).

Decisions (chosen defaults, noted to user at end)

    cyberware requirement = nullable free-text column cyberware_req on all 3 tables (catalog_guns, store_stock, inventory_items), with datalist suggestions from the cyberware catalog. Free text matches existing string conventions (power_level etc.) and allows combos / off-catalog names. Displayed as a "REQUIRES: X" badge everywhere.
    pictures + wiki link + prefab link live on catalog_guns (the registry), mirroring property/housing. Store/inventory rows have no image column -> hover preview is catalog-scoped. (Offer to extend later.)
    Hover preview uses existing shadcn HoverCard primitive on the gun name in the catalog list.
